# dialog
The &lt;dialog> tag in HTML is a native way to create modal windows or pop-up dialogs — without using any external JavaScript libraries or frameworks like Bootstrap or jQuery UI.  It’s part of HTML5 and is still relatively underused, but it’s extremely useful and powerful.

# Key features

<dialog> creates a built-in popup box that can display content like text, buttons, or forms.

.showModal() displays the dialog centered on the screen and disables interaction with the rest of the page.

.close() hides the dialog.

It’s accessible and can be customized easily with CSS.

You can also use .show() (instead of .showModal()) if you want a non-blocking dialog.

# Why it’s useful

No need for external libraries or complex CSS/JS.

Works natively in modern browsers.

Great for showing alerts, confirmations, forms, or help messages.

Easy to style and animate.
